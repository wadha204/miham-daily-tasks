# مِهام

تطبيق عربي بسيط وهادئ لترتيب مهام اليوم ومتابعة نسبة الإنجاز.

## الرابط العام

[افتح تطبيق مِهام](https://wadha204.github.io/miham-daily-tasks/)

نسخة GitHub Pages موجودة داخل مجلد `docs/` وتعمل بالكامل في المتصفح. تُحفظ المهام محليًا على جهاز المستخدم، لذلك لا تحتاج إلى حساب أو تسجيل دخول.

## تشغيل نسخة التطوير

يتطلب Node.js إصدار `22.13.0` أو أحدث.

```bash
npm install
npm run dev
```

للتحقق من البناء:

```bash
npm run build
```
